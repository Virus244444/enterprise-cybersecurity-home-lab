# Lab Setup Guide

## Project Overview

This lab is designed to simulate an enterprise cybersecurity environment for security monitoring, threat detection, and incident response.

## Host Machine

- Operating System: Windows 11
- RAM: 16
- Processor: 4.5GHz

## Virtualization Software

- VirtualBox

## Virtual Machines

### Windows 11 VM

- Purpose: Target workstation
- RAM: 4 GB
- Storage: 50 GB
- Status: Planned

### Kali Linux VM

- Purpose: Security testing and attack simulation
- RAM: 4 GB
- Storage: 40 GB
- Status: Planned

## Tools To Be Installed

- Sysmon
- Splunk
- Nmap
- Wireshark
- Burp Suite
